# Easy Dock

iOS 风格的 Windows 底部 Dock。屏幕底边一条悬浮面板，图标悬停放大、相邻图标被自然推开，点一下启动程序。

纯 Python 标准库（`tkinter` + `ctypes`），不需要安装任何第三方包，绿色免安装、不联网。

![Easy Dock](screenshot.png)

## 快速开始

1. 双击 **`启动 Dock.bat`** —— Dock 出现在屏幕底部中央；
2. 鼠标移到图标上会放大，点一下启动；
3. 右键图标：**打开 / 从 Dock 移除**；右键空白处：**添加应用 / 重新居中 / 退出 Dock**；
4. 关闭：右键 →「退出 Dock」，或双击 **`关闭 Dock.bat`**。

## 交互

| 操作 | 效果 |
| --- | --- |
| 鼠标悬停 | 该图标放大到 1.75×，左右相邻放大到 1.25×，更远的保持原尺寸 |
| 左键点击 | 启动该程序（支持 exe / lnk / 批处理 / `ms-settings:` 这类 URI） |
| 右键图标 | 打开、从 Dock 移除 |
| 右键空白 | 添加应用（文件选择框）、重新居中、退出 |
| 面板外区域 | 鼠标点击可穿透到桌面或下面的窗口 |

## 配置

同目录 `config.json`，首次运行自动生成。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `icon_size` | `48` | 图标基准边长（像素），改完会重新提取 2× 图 |
| `gap` | `10` | 图标间距 |
| `padding` | `10` | 面板内边距 |
| `radius` | `18` | 面板圆角半径 |
| `bg` | `#1F1F24` | 面板底色，同时也是图标透明区的压平底色 |
| `border` | `#3A3A42` | 面板描边色 |
| `topmost` | `true` | 是否始终置顶 |
| `items` | 自动挑选 | 应用列表 |

`items` 里每一项：

| 键 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | 显示名，也是无图标时的磁贴首字 |
| `target` | 是 | exe / `.lnk` / `.bat` / `ms-settings:` 等 URI |
| `icon` | 否 | 单独指定图标来源（`.lnk` 解析不到目标时用这个兜底） |
| `args` | 否 | 启动参数 |

首次运行会从开始菜单和桌面里挑 7 个常见程序，再加一个「设置」。想换成自己的，直接在 `items` 里改，或右键「添加应用」。

## 图标是怎么来的

1. 解析 `.lnk` 二进制（LinkInfo 的 LocalBasePath，或环境变量数据块）拿到真实 exe，**不依赖 COM/pywin32**；
2. 用 `PrivateExtractIconsW` 按 `icon_size × 2` 提取大图标，失败回退 `SHGetFileInfoW`；
3. 转 PNG 时把 alpha **压平到面板底色** —— Tk 画布画不出半透明，不压平就会出现黑边；
4. 缓存到 `icons/`，文件名是 `target + 底色 + 尺寸` 的哈希，所以改底色或改尺寸会自动重新生成。

`File Explorer.lnk` 这类纯 IDList 的快捷方式解析不到目标，默认配置里用 `icon` 字段直接指向 `C:\Windows\explorer.exe`，避免出现快捷方式小箭头。

## 界面是怎么实现的

| 要点 | 做法 |
| --- | --- |
| 无边框、不进任务栏 | `overrideredirect(True)` |
| 圆角外真透明 | `-transparentcolor` 色键（`#010203`），实测点击可穿透 |
| 放大不撕裂 | 4 档整数缩放（1 / 1.25 / 1.5 / 1.75），用 `zoom().subsample()` 命中整数比 |
| 相邻图标被推开 | 每次按「当前实际宽度」重排整行，而不是固定坐标缩放 |
| 边缘不被裁切 | 窗口左右各留 `icon_size × 0.9` 的余量，面板本身宽度不变 |
| 动画 | 16ms 帧循环，当前值向目标值插值 35%/帧 |

## 已知限制

- 圆角是硬边：Tk 画布没有抗锯齿，也没做投影（真投影需要分层窗口 + 逐像素 alpha）；
- 暂不支持拖拽排序、自动隐藏、运行中指示点、多显示器分别定位；
- 放大只作用于悬停项和左右相邻项，更远的图标不动；
- 始终置顶，全屏应用/游戏时也会浮在上面；
- 关闭脚本依赖 `dock.pid`，若进程被强杀，pid 文件会残留，再点关闭会提示失败，删掉该文件即可；
- 开发环境的沙箱会杀掉带弹出菜单的进程，所以右键菜单只能在真实桌面验证（Tk 标准菜单，正常可用）。
